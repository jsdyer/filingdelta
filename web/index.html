HOW TO READ THIS

Evidence first.
Comparisons with context.

What is collected?

SEC EDGAR Submissions and Company Facts, captured once daily by a scheduled collector. Six companies, selected standard US GAAP and IFRS monetary concepts, and periods ending in 2018 or later. Custom company-specific XBRL tags and many metrics are outside this collection. All displayed numbers are reported source values.

What does “changed” mean?

We compare the same company's exact taxonomy/concept, unit, start and end dates across SEC filings. Different dates or currencies are never joined. Multiple values in one filing are labelled ambiguous and excluded from the numeric comparison. Comparative figures can be recast or use different accounting contexts: inspect the original filings before drawing conclusions.

Fiscal periods, currency and percentages

“Annual” and “~3 months” group periods by their actual duration, not the SEC fiscal-year labels attached to a filing. Fiscal years need not match calendar years. We never subtract year-to-date facts to invent quarters. Displayed differences use the latest reported value for each exact period; percentage change divides by the absolute comparison value. A zero baseline has no percentage. Currency units remain separate.

Refreshes, history and privacy

Scheduled collection runs at 08:45 UTC; GitHub may delay it. The site shows the actual capture time. A failed collection keeps the last good capture. The latest 90 successful captures are available here; older committed captures remain in Git history. SEC filings may predate our first capture; that is filing history, not a claim that we collected those values at the time.

Search and filtering happen in your browser over the published snapshot. No financial account, API key or transaction information is requested. Downloads remain on your device. Source links open SEC pages; the site also loads CoolCode's shared visit counter.
